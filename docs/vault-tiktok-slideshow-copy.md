# VAULT — TikTok Slideshow Copy (6-slide format)

**Status:** Pre-research draft. Written from positioning + category knowledge, not from verbatim voice-of-customer data. Hooks should be revisited once the Deep Research returns real quotes.

---

## Format rules these follow

- **Slide 1 is 80% of performance.** Readable in under one second, lands a pain point, never the product.
- **6 slides.** Arc is: hook → pain detail → reframe → product → proof → close.
- **One idea per slide.** Max ~14 words.
- **Product appears slide 4–5.** Lead with the wound.
- **Second person, present tense.**

## Compliance guardrails

- Dollar figures framed as examples, never promises. Any slide showing a number carries **"Illustrative example"** on-screen.
- No "financial advice," no guaranteed returns.
- Bank access described as **read-only via Plaid** wherever the connection is mentioned.
- No conspiracy framing. "Your bank doesn't tell you" is fine; "banks are hiding this" is not.
